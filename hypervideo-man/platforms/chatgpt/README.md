# ChatGPT setup

Two routes. Pick the Custom GPT for a reusable assistant you can share; pick a Project for private work with files and chat history in one place.

## Route A — Custom GPT (recommended)

1. Download `hypervideo-man/dist/hypervideo-man-chat-kit.zip` and unzip it on a computer.
2. In ChatGPT, open Explore GPTs → Create → Configure.
3. Fill Name, Description, Instructions, Conversation starters, Knowledge and Capabilities exactly as listed in `GPT_CONFIG.md`.
4. Save with "Only me" first. Test with starter 1: expect a one-line readiness report, an intake table, at most three questions and copy-ready prompt blocks.
5. Change sharing to "Anyone with the link" when you are happy with it.

## Route B — ChatGPT Project

1. Create a Project named HyperVideo Man.
2. Open Project settings → Instructions and paste `02b_ChatGPT_Instructions.md`.
3. Add the 17 files from `knowledge/` to the Project files.
